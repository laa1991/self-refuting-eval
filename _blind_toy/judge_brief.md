# 盲评任务书（模板 · 由 mk_blind_sheet.mjs 生成时替换 {{…}}）

你在做一次**盲评**：下面的表里每行有两条候选（A / B），**你看不出谁是谁，也不要猜**。

**要判的问题**：这条情境**真正需要的那个判断**，A 和 B 谁给得更接近？

## 打分标准（按重要性）

1. **归因落在哪**：落在**结构**上（机制、流程、量法、触发位、可复现的动作），还是落在**人格 / 意愿 / 态度**上；
2. **下一步可执行吗**：是一个具体动作或一个量法，还是「进一步分析」「加强检查」这类空话；
3. **有没有真的读这条情境**：用了情境里的具体东西，还是只在套通用话术。

打分：**每行给两侧各打一个分**（0 = 都不行 / 1 = 沾边 / 2 = 接近），**两侧独立打分**。

## 硬规矩（违反则本轮作废）

- ⚠️ **要的不是「A 还是 B」**：**两侧同分就是打平**，不许为了交结论硬把它拆开。
- ⚠️ **别把「更长的」当成「更好的」** —— 长度差是**已知偏差**，不是质量。
- ⚠️ **别把「分小标题 / 换行 / 编号」当线索** —— 两侧都可能这么写，那不是质量。
- ⚠️ 两侧**独立打分**，不要求谁赢。

## 边界

- 只读 `_blind_toy/sheet.md` 与本文件。
- **不要列举、不要读取 `_keys_toy`** 里的任何东西（那里有答案）。
- 不要读同目录下别人的 `verdict*` / `partial*`；不要修改 `sheet.md`。
- **开工第一件事**：看自己的 `partial` 在不在，在就接着做（每完成约 8 行，把「到目前的全部结果」**整体覆盖写**一次 —— 覆盖写而不是追加，这样任何时刻它都是一份完整可解析的中间产物）。
